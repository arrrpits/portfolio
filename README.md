## About

I work across software development with a focus on **Python, SQL, RESTful microservices, and cloud workflows**. The portfolio also highlights my problem-solving practice, including **1,000+ algorithmic problems solved**.

## Run Locally

No build step is required for the current static website.

1. Clone the repository:

   ```bash
   git clone https://github.com/arrrpits/portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser.

You can also use the VS Code **Live Server** extension to preview the site locally.
